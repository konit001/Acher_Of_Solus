Skill Tree

prototype สำหรับทดสอบลอจิกของ SkillTreeManager ก่อนต่อ UI จริงใน Unity

0 แต้มสกิล

แผงทดสอบ

    โบนัสจาก passive ที่ปลดแล้ว

    สถานะช่อง

    Locked Available แต่แต้มไม่พอ Available กดได้ Unlocked

    แมปกลับไปหาโค้ด C#

    • ลอจิกทั้งหมด = SkillTreeManager.cs — ชื่อเมธอดใน JS ตรงกับของจริงทุกตัว
    • ช่อง 1 ช่อง = SkillSlotUI (ยังไม่ได้สร้าง) เทียบ StatusEffectIconSlot
    • ทั้งหน้า = SkillTreeUi (ยังไม่ได้สร้าง) เทียบ StatusEffectUi
    • แผงทดสอบ = [ContextMenu] ที่อยู่ท้าย SkillTreeManager

    ต่างจากของจริงตรงไหน

    • getState() ที่นี่คีย์ด้วย skillId เพราะ JS ไม่มี reference ของ ScriptableObject
    • เหตุผลที่ปลดไม่ได้ในแถบ log คำนวณแยกต่างหาก — TryUnlock() จริงคืนแค่ bool
    • ข้อมูลสกิลเป็นของสมมติ ไม่ได้อ่านจาก .asset จริง

    ยังไม่ได้จำลอง

    • เส้นเชื่อมระหว่างช่องที่บอกว่าสกิลไหนต่อจากสกิลไหน — ตอนนี้ดูได้จากบรรทัด "ต้องปลด …" เท่านั้น
    • tooltip ตอน hover (ตกลงกันว่าจะเปลี่ยนไปใช้ทีหลัง)
    • cooldown ของ active skill — SkillState รอบนี้ยังไม่เก็บ
    • การเซฟ/โหลดสกิลที่ปลดไว้
